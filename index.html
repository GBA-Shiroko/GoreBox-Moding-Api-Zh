物理命令

AddRigidbody

为物体添加刚体（Rigidbody）组件，开启物理交互。若物体已有刚体，则把现有刚体注册给脚本使用。
返回值：新增刚体成功返回 true；已存在刚体返回 false。
AddRigidbody

AddForce(x, y, z, mode)

对已注册的物理物体施加力，力的类型由 mode 决定。
x / y / z：力的三轴分量。
mode：施加的力模式（见下表）。
AddForce({"x": 0, "y": 0, "z": 0, "mode": 0})
mode模式说明
0Force（持续力）持续施加力，会受物体质量影响。
1Acceleration（加速度）持续施加加速度，忽略质量。
2Impulse（冲量）瞬时施加一次力的冲量，受质量影响。
3VelocityChange（速度变化）直接改变瞬时速度，忽略质量。

RemoveRigidbody

移除物体的刚体组件，关闭物理交互。
返回值：移除成功返回 true；找不到刚体返回 false。
RemoveRigidbody

父子关系与位移、旋转、缩放

关于父子绑定：把一个物体（子物体）链接到另一个物体（父物体）上，子物体会跟随父物体移动。这是搭建复杂物体和角色骨架的基础。通常只需要给父物体加刚体，由它带动子物体；除非特意挂有关节，否则不建议给子物体再加刚体，否则可能出现不可预料的物理行为。
关于本地坐标：物体的本地位置、旋转始终相对于父物体。把本地位置和旋转全部置零，物体就会与父物体对齐。

SetParent(parent)

把当前物体的父物体设置为另一个已注册物体。
SetParent({"name": "parentName"})

MoveLocal(x,y,z)相对父物体的朝向移动。
SetPosition(x,y,z)直接设置物体世界坐标。
SetLocalPosition(x,y,z)设置相对于父物体的本地坐标。
Move({"x": 0, "y": 0, "z": 0})
MoveLocal({"x": 0, "y": 0, "z": 0})
SetPosition({"x": 0, "y": 0, "z": 0})
SetLocalPosition({"x": 0, "y": 0, "z": 0})

函数说明

Rotate(x,y,z)按世界坐标系旋转。
RotateLocal(x,y,z)相对父物体朝向旋转。

Rotate({"x": 0, "y": 0, "z": 0})
RotateLocal({"x": 0, "y": 0, "z": 0})

函数说明

事件监听

⚠️ 必备事件循环：要让事件监听生效、回调被调用，下面这段循环必须放在脚本最末尾。不进入这个循环，所有事件都不会触发。 
while true
    while _events.len > 0
        _nextEvent = _events.pull
        _nextEvent.invoke(_nextEvent.args)
    end while
    yield
end while

ListenForPlayer / EndListenForPlayer

开启 / 关闭本地玩家相关事件。开启后脚本会调用下列玩家回调函数。
回调函数触发时机
OnLocalTakeDamage(damage)玩家受到伤害，附带伤害数值 args.damage。
OnLocalDied玩家死亡。
OnLocalInfected玩家被感染或被解除感染。
OnLocalHealed玩家完全回血。
OnLocalKnockout玩家被击晕倒地。
OnLocalWakeUp玩家从击晕状态苏醒。
OnLocalSpawned玩家重生 / 生成。
OnLocalRagdoll玩家进入布娃娃（Ragdoll）状态。
OnLocalGetUp玩家从布娃娃状态爬起。
OnLocalEmote(emoteName)玩家播放表情动作，附带表情名字。
OnLocalEmoteEnd表情动作结束。
示例：
OnLocalTakeDamage = function(args)
    damageAmount = args.damage
    print "哎哟！受到 " + damageAmount + " 点伤害！"
    if damageAmount < 5 then
        print "还好，不怎么疼。"
    else
        print "还是挺疼的。"
    end if
end function

ListenForServer / EndListenForServer

开启 / 关闭服务器相关事件。
回调函数触发时机
OnPlayerJoined(player)有玩家加入服务器，附带玩家名。
OnPlayerLeft(player)有玩家离开服务器，附带玩家名。
OnKilledPlayer(player)本地玩家击杀了其他玩家，附带受害者名字。

ListenForChat / EndListenForChat

开启 / 关闭聊天事件。
回调函数触发时机
OnChatMessage(sender, message)收到聊天消息，附带发送者用户名和消息内容。

ListenForInventory / EndListenForInventory

开启 / 关闭背包操作事件。
回调函数触发时机
OnItemSelect(slot)玩家切换 / 装备物品，附带背包槽位编号。

ListenForInstantiation / EndListenForInstantiation

开启 / 关闭物体生成事件。
回调函数触发时机
OnInstantiate(player, name)物体被生成，附带生成者名字和物体名字。

ListenForSceneChange / EndListenForSceneChange

开启 / 关闭场景切换事件。
回调函数触发时机
OnSceneChanged(sceneName)加载新地图 / 场景，附带场景名字。

ListenForInput / EndListenForInput

开启 / 关闭按键输入事件。
回调函数触发时机
OnKeyPress(key)按键按下，附带键名。
OnKeyHold(key)按键持续按住，附带键名。
OnKeyLift(key)按键松开，附带键名。

对象管理

SetTexture(name)

获取物体的渲染器，把材质贴图设置为已加载的指定贴图（按名字引用）。
SetTexture({"name": "myTexture"})

InstantiateEmpty(name, x, y, z, rotX, rotY, rotZ, rotW)

在指定位置和旋转下创建一个空物体。该物体会自动注册，可用于 Destroy、ExecuteScript 等命令。
InstantiateEmpty({"name": "emptyObject", "x": 0, "y": 0, "z": 0, "rotX": 0, "rotY": 0, "rotZ": 0, "rotW": 0})

InstantiateEmptyChild(name, x, y, z, rotX, rotY, rotZ, rotW)

在当前物体下创建一个空子物体，位置旋转相对当前物体。自动注册。
InstantiateEmptyChild({"name": "emptyChildObject", "x": 0, "y": 0, "z": 0, "rotX": 0, "rotY": 0, "rotZ": 0, "rotW": 0})

InstantiateModelChild(model, name, x, y, z, rot…, scale, collisions, convex)

把已加载的模型生成为当前物体的子物体，可设置名字、位置、旋转、缩放（相对当前物体），并可选是否开启碰撞（可设为凸碰撞）。模型自动注册。
InstantiateModelChild({"model": "myModel.fbx", "name": "myModel", "x": 0, "y": 0, "z": 0, "rotX": 0, "rotY": 0, "rotZ": 0, "rotW": 0, "scale": 1, "collisions": true, "convex": true})

InstantiateModel(model, name, x, y, z, rot…, scale, collisions, convex)

把已加载的模型生成到场景中（非子物体），可设置名字、位置、旋转、缩放，并可选是否开启碰撞（可设为凸碰撞）。模型自动注册。
InstantiateModel({"model": "myModel.fbx", "name": "myModel", "x": 0, "y": 0, "z": 0, "rotX": 0, "rotY": 0, "rotZ": 0, "rotW": 0, "scale": 1, "collisions": true, "convex": true})

Instantiate(name, path, x, y, z, rotX, rotY, rotZ, rotW)

从游戏内置资源路径生成一个指定名字的物体，位置和旋转可设置。自动注册。
Instantiate({"name": "spawnedDoll", "path": "AI/GoreDoll", "x": 0, "y": 0, "z": 0, "rotX": 0, "rotY": 0, "rotZ": 0, "rotW": 0})
建议使用唯一的物体名字，避免识别困难和意外重复；在联机场景中，某些情况下只应由房主（Host）生成物体。

ExecuteScript(target, script)

在已注册的目标物体上执行一段已有的用户脚本。
ExecuteScript({"target": "spawnedDoll", "script": "aiScript"})

ExecuteScriptOnChildren(target, script)

在目标物体的所有子物体上执行一段已有的用户脚本。
ExecuteScriptOnChildren({"target": "spawnedDoll", "script": "aiScript"})

Destroy(name)

销毁一个已注册的物体。
Destroy({"name": "spawnedDoll"})

DestroySelf

销毁当前物体自身。
DestroySelf

聊天功能

自定义指令：借助聊天 API，你可以添加自定义命令增强互动。玩家发送的消息中，只有以 ? 开头的消息会被识别为自定义命令，不会发到公聊；若 ListenForChat 处于开启状态，会被 OnChatMessage 捕获。 
OnChatMessage = function(args)
    if message == "die" then
        PlayerKill
    end if
end function

SendChatMessage(sender, message)

向所有玩家发送一条聊天消息，可自定义发送者名字和内容，支持富文本格式。
SendChatMessage({"sender": "Bank", "message": username + " 目前拥有 " + cash + "GB$"})

SendChatMessageLocal(sender, message)

仅向执行脚本的本地玩家显示消息，其他玩家看不见。支持富文本格式。
SendChatMessageLocal({"sender": "Bank", "message": "你当前拥有 " + cash + " GB$"})

SendErrorMessage(message)

发送一条本地错误提示，仅执行脚本的玩家可见。
SendErrorMessage({"message": "这是一条错误提示"})

逻辑工具函数

StringContains(string, target)

判断给定字符串是否包含指定子串，适合做关键词检测。包含时返回 true。
if StringContains({"string": "hello, may I have some money?", "target": "money"}) then
    SendChatMessage({"sender": "Bank", "message": "没问题！"})
    GiveCurrency({"amount": 500})
end if

RandomInt(min, max)

在 min 与 max 之间生成随机整数，上限不包含在内。
x = RandomInt({"min": 0, "max": 10})
print x
if x == 9 then
    print "幸运数字！"
end if

RandomFloat(min, max)

在 min 与 max 之间生成随机浮点数，上限不包含在内。
x = RandomFloat({"min": 0, "max": 10})
print x
if x >= 9.9 then
    print "这只有 1% 的概率发生！"
end if

localPosX / localPosY / localPosZ本地坐标（相对父物体），受父物体位置影响。

旋转

变量说明

缩放与子物体

变量说明
scaleX / scaleY / scaleZ本物体缩放（相对父物体）。
childCount子物体数量。只读

游戏数据

变量说明

infected玩家是否被感染（true / false）。
isHost玩家是否为主机房主（true / false）。

存档读写

通过一个「键名（key）」来标识和取回数值。例如用键名 "score" 保存分数，之后再用同一个键名读取。

SaveFloat(key, value)

安全保存一个浮点数。
SaveFloat({"key": "hunger", "value": 34.2})

SaveInt(key, value)

安全保存一个整数。
SaveInt({"key": "score", "value": 100})

SaveString(key, value)

安全保存一个字符串。
SaveString({"key": "rank", "value": "chief"})

GetFloat(key, defaultValue)

读取已保存的浮点数；读不到时返回默认值。
GetFloat({"key": "hunger", "defaultValue": 100})

GetInt(key, defaultValue)

读取已保存的整数；读不到时返回默认值。
GetInt({"key": "score", "defaultValue": 0})

GetString(key, defaultValue)

读取已保存的字符串；读不到时返回默认值。
GetString({"key": "rank", "defaultValue": "jobless"})
